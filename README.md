# E. coli Whole Genome Sequencing Pipeline

## Objective
To perform variant analysis on E. coli using NGS data.

## Dataset
SRA accession: SRR33679551

## Tools Used
- FastQC
- BWA
- SAMtools
- GATK

## Workflow
1. Quality Control
2. Alignment
3. BAM processing
4. Variant Calling

## Output
- BAM file
- Sorted BAM
- VCF file
